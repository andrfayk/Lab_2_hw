# Домашнее задание к работе №2
Вариант 15

## Условие задачи
Стоимость погонного метра красного шелка стоит Х золотых. Сколько заплатил Грей за ткань для своей бригантины, если общая площадь парусов на ней S м², а ширина ткани в рулоне L см.

## 1. Алгоритм и блок-схема
### Алгоритм:
1. Начало.
2. Задать переменные:
- **X** — цена погонного метра шелка (25 золотых);
- **S** — общая площадь парусов (150 м²);
- **L** — ширина ткани в рулоне (120 см).
3. Вычислить длину ткани **length = S / (L / 100)** (ширину переводим из сантиметров в метры: 120 см = 1.2 м).
4. Вычислить стоимость **price = X · length**.
5. Вывести условие задачи с подставленными значениями и ответ.
6. Конец.

## 2. Реализация программы
```c
#include <stdio.h>
#include <locale.h>


int main() {
    setlocale(LC_CTYPE, "RUS");
    int X = 25;
    int S = 150;
    int L = 120;
    float length = S / (L / 100.0); // длина ткани: площадь парусов делим на ширину рулона в метрах (120 см = 1.2 м)
    float price = X * length; // цена погонного метра, умноженная на длину ткани
    printf("Стоимость погонного метра красного шелка стоит %d золотых. Сколько заплатил Грей\nза ткань для своей бригантины, если общая площадь парусов на ней %d м2,\nа ширина ткани в рулоне %d см.\nОтвет: %.2f золотых", X, S, L, price);
    return 0;
}
```
